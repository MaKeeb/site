# MaKeeb site

The website for [MaKeeb](https://github.com/MaKeeb/app), an on-screen keyboard for Android and iOS: the landing page and the privacy policy. Built with [Astro](https://astro.build) and published to GitHub Pages at https://makeeb.github.io/site/.

```
npm ci
npm run dev       # http://localhost:4321/site/
npm run build     # type check and build into dist/
```

Pushing to `main` deploys (`.github/workflows/deploy.yml`).
